# Evaluation Results Output Files

This folder contains the evaluation results saved in multiple formats for easy analysis and record-keeping.

**Note**: Results are now saved in an `evaluation_{checkpoint_name}/` subfolder within the checkpoint directory (e.g., `evaluation_model_epoch_100` for a checkpoint named `model_epoch_100.ckpt`), keeping evaluation results organized by checkpoint.

## File Descriptions

### 1. `evaluation_summary.csv`
Contains the main evaluation metrics:
- `metric`: Name of the evaluation metric
- `value`: Corresponding metric value

### 2. `evaluation_metadata.csv`
Contains metadata about the evaluation run:
- `evaluation_time`: Timestamp when evaluation was completed
- `model_path`: Path to the evaluated model checkpoint
- `model_steps`: Number of steps used for model inference
- `sample_steps`: Number of steps used for sampling
- `num_sample_batches`: Number of sample batches generated
- `num_samples_per_batch`: Number of samples per batch
- `total_samples`: Total number of samples generated

### 3. `evaluation_results_combined.csv`
Combines metadata and summary results in a single file for easy analysis.

### 4. `generated_sequences.csv`
The actual DNA sequences generated by the model:
- `sample_id`: Unique identifier for each sample
- `dna_sequence`: Generated DNA sequence string

### 5. `evaluation_results.npz`
Original NPZ format containing all numerical results in compressed format.

## Usage Notes

- All CSV files are saved in the `evaluation_{checkpoint_name}/` subfolder within the checkpoint directory
- The folder name includes the checkpoint filename (without extension)
- This keeps evaluation results organized by specific checkpoint
- The metadata includes evaluation time, model configuration, and sampling parameters
- Use the combined CSV for quick overview of results
- The sequences CSV allows for further bioinformatics analysis
- All files are automatically created when running the evaluation script

## Example Analysis

```python
import pandas as pd

# Load summary results (adjust path to your checkpoint directory)
checkpoint_dir = "/path/to/your/checkpoint"
checkpoint_name = "model_epoch_100"  # or whatever your checkpoint is named
summary = pd.read_csv(f'{checkpoint_dir}/evaluation_{checkpoint_name}/evaluation_results_combined.csv')
print(summary)

# Load generated sequences for further analysis
sequences = pd.read_csv(f'{checkpoint_dir}/evaluation_{checkpoint_name}/generated_sequences.csv')
print(sequences.head())

# Load metadata
metadata = pd.read_csv(f'{checkpoint_dir}/evaluation_{checkpoint_name}/evaluation_metadata.csv')
print(metadata)
```
